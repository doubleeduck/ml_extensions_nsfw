# Nude Moon и вход AllHentai — 2026-10-20

Официальный пакет содержит 30 источников: сохранены все 29 прежних ID,
добавлен `ru.nudemoon`. Для исправления сетевого доступа и загрузки иконок

## Nude Moon

- База: `https://nude-moon.org`, русский язык, признак NSFW.
- Популярное: `/all_manga?views`, новое: `/all_manga?date`.
  Пагинация использует `rowstart=30*(page-1)`, как ссылки самого сайта.
- Сортировки: `date`, `views`, `com`, `like`, `pages`.
- Теги загружаются из бокового меню `/all_manga` (90 вариантов при проверке),
  доступны множественный выбор и обновление списка. Значения берутся из ссылок,
  названия сохраняют пробелы. Комбинация использует UTF-8 путь вида
  `/tags/романтика+цветная+&date&rowstart=30`; сортировка и следующая страница
  сохраняют все выбранные теги. Поиск по названию использует отдельный endpoint
  сайта и не применяет теги; это указано в подписи фильтра.
- ID манги и единственной главы — числовой ID галереи. Слаги в каталоге,
  на главной и в ридере различаются, поэтому они не входят в ID библиотеки.
  Проверены адреса `/{id}-manga.html` и `/{id}-online-manga.html?row`.
- Карточка: название, обложка, описание, автор, теги и количество страниц.
  Глава также сохраняет дату публикации. Неподтверждённые статус и год — null.
- Режим `?row` содержит все картинки, включая `data-src` и файлы с именами
  переводчиков. Скрипты сайта не выполняются парсером.
- HTML декодирует HTTP-host по объявленному сайтом Windows-1251. Поисковый
  параметр `stext` кодируется в той же кодировке, как форма в браузере.
- Единственный HTML/media/auth origin — `https://nude-moon.org`.
  Форма входа находится на главной; cookies изолированы по sourceId.

На момент проверки `/search?stext=...` отдавал HTTP 200 только с шапкой и
подвалом: без title и карточек, для английских и русских запросов. Источник
выдаёт `parse_error`, а не ложный пустой результат. Поиск без текста использует
каталог с выбранной сортировкой.

Первоначальный Dart HTTP-транспорт получал Cloudflare challenge (403), хотя
браузер открывал сайт. Даже перенос анонимного `cf_clearance` с совпадающим UA
не исправил этот транспорт. Штатный WinHTTP вернул HTTP 200 без cookies.
Поэтому Nude Moon явно объявляет `network.transportProfile: 'host.platform.v1'`:
Windows использует WinHTTP, Android — Cronet с системным DNS. Брокеры приложения
сохраняют проверку origin, redirects, source-scoped сессий, отмены и лимитов.
Тот же профиль используется для обложек и страниц. Другие источники сохраняют
прежний транспорт. При настоящем challenge каталог предлагает открыть WebView;
его User-Agent согласован с подписанным профилем источника.

Повторная живая проверка в Windows прошла через JS LPAC, HTTP и media broker:
30 карточек в популярном, карточка и глава, 27 URL страниц, HTTP 200 для
обложки (102928 байт) и первой страницы ридера (649446 байт). Использовалось
пустое тестовое хранилище, без пользовательских аккаунтов. Android-устройство
отдельно не проверялось.

## Иконки из расширений

Все 30 источников объявляют `branding.icon` и `branding.accentColor` в manifest.
27 уникальных изображений находятся в `assets/source_logos/` пакета и защищены
подписью и SHA-256. Nude Moon использует оригинальный `favicon.jpg` сайта.
Приложение читает байты только из проверенных установленных пакетов; встроенный
реестр логотипов удалён. При установке, обновлении и удалении иконки обновляются
через уведомление метаданных. Если иконки нет, показывается нейтральный значок.
Допускаются PNG/JPEG/WebP до 256 КиБ; удалённые URL и необъявленные файлы запрещены.
Логотипы самостоятельных интеграций трекеров находятся отдельно в приложении,
в `assets/tracker_logos/`, поскольку трекеры не зависят от установки источников.

## AllHentai

В браузере выполнен переход по «Вход» на `https://20.allhen.online/`.
Обработчик ссылки `/internal/auth` открывает:

```text
https://z.qawa.org/internal/auth/login?siteId=1&targetUri=%2Flogin%2FcontinueSso%3FsiteId%3D1%26targetUri%3D%252F
```

После декодирования внешнего `targetUri`:

```text
/login/continueSso?siteId=1&targetUri=%2F
```

Форма отправляется методом POST на `/login/authenticate?ttt=<timestamp>&siteId=1`.
Поля: `targetUri`, `username`, `password`, `remember_me`, `_remember_me_yes`,
`remember_me_yes`. Значение `ttt` формирует сайт; расширение его не фиксирует
и форму не отправляет. Пользовательские учётные данные не использовались.

Для `ru.allhentai` изменены login URL, auth/success origin и cookie grants
(`z.qawa.org`, `qawa.org` вместо GroupLe). Completion остаётся на сайте
источника. Остальные источники GroupLe продолжают использовать прежний вход
через `3.grouple.co`. Профиль `host.grouple.v1` и отдельные сессии сохранены.
